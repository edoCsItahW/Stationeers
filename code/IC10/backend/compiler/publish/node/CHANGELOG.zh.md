# 变更日志

[English](CHANGELOG.md)

> 本包以 Node.js 原生扩展的形式封装 IC10 编译器 C++ 核心，因此条目既可能是**绑定层**的变更
> （导出的适配器、类型声明、打包内容），也可能是该扩展所暴露的**编译器行为**变更。

## 2026/06/25

- [1.0.0]: 发布 1.0.0

## 2026/06/29

- [1.0.1]: 修复在 VSCode 中导入该模块时崩溃的问题
- [1.0.2]: 关闭调试输出

## 2026/07/03

- [2.0.0]: 编译器优化（两轮），并统一 Node.js 的使用方式

## 2026/07/09

- [2.1.0]: 支持增量编译（行级词法缓存 + 语句级语法缓存）

## 2026/07/22

- [2.3.0]: 重新打包：发布 `types/`（`index.d.ts` 及词法/语法/语义各声明文件）与 `static/`，并加入 `@types/node` 开发依赖
- [2.3.0]: 语言侧支持注解语法，链接器（Linker）导出到 Node.js

## 2026/07/23

- [2.4.0]: 向绑定层暴露 LSP 悬停所需数据（别名、标签、常量、指令关键字）

## 2026/07/25

- [2.4.1]: 向绑定层暴露 LSP 语义标记

## 2026/07/26

- [2.5.0]: 向绑定层暴露 LSP 补全，并导出类型表

## 2026/07/27

- [2.6.0]: 从链接器导出类型表

## 2026/07/29

- [2.6.1]: 修复词法分析器的转义处理
- [2.6.3]: 修复增量解析刷新缓存令牌位置导致的错位；增强错误恢复

## 2026/07/30

- [2.6.4]: 修复跳转目标范围错误

## 2026/07/31

- [2.6.6]: 修复若干插件反馈的错误

## 2026/08/21

- [2.7.0]: **包名由 `ic10-node-api` 改为 `ic10c-node`**（原生模块 `src/ic10-node-api.node` → `src/ic10c-node.node`）；修复 VS Code 导入崩溃问题
- [2.7.2]: 为 VS Code 插件提供运行时支持

## 2026/09/24

- [3.0.0]: IC10 v3 —— 重写词法与语法分析并统一按元数生成的 AST，调整 `annotation` 与 `link` 语法规则，解决预定义常量问题，同时修补元数据与标准库
- [3.0.1]: 修复增量编译部分问题，放宽部分语法限制
